
# Feed News

A simple RSS news aggregator that displays content from major news portals.

Originally created in 2014 and updated in 2018, this project was developed to explore the Slim Framework.

## Prerequisites

Make sure Docker and Docker Compose are installed and the Docker engine is running.

## Run Locally

1. Clone the repository:

```bash
git clone git@github.com:brlivramento/feeds_news.git
cd feeds_news
```

2. Start the application:

```bash
docker compose up --build
```
