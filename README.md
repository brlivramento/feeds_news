# Feed News

A news viewer based on feeds (RSS) from some major news portals.
A basic project, originally created in 2014 and updated in 2018, intended for testing the Slim Framework at the time.

## Prerequisites

Make sure Docker and Docker Compose are installed and Docker Desktop is running.
    
## Run Locally

1. Clone the project

```bash
  git clone git@github.com:brlivramento/feeds_news.git
  cd feeds_news
```

2. Build docker

```bash
  docker compose up --build
```
